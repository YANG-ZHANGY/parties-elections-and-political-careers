# 政黨、選舉與政治生涯

[English](README.md) · [Yang ZHANG](https://github.com/YANG-ZHANGY)

政黨組織、政治競爭、選舉訊號，以及跨層級的政治生涯。

## 研究項目

| 項目 | 核心問題 |
| :--- | :--- |
| [政黨制度與議會暴力](projects/legislative-violence.zh-Hant.md) | 議會競爭在什麼條件下升高為肢體衝突？ |
| [跨層級政治生涯機會](projects/cross-tier-career-opportunities.zh-Hant.md) | 不同政治層級的機會，如何進入區域立法者的生涯選擇？ |
| [候選人結盟與區域優勢](projects/candidate-alignment.zh-Hant.md) | 候選人為什麼在某些情境與政黨結盟，在其他情境維持不同的選舉位置？ |
| [台灣認同、分歧與第三勢力投票](projects/taiwan-third-force-voting.zh-Hant.md) | 政治分歧的改變，如何形塑第三勢力的支持者結構？ |
| [選舉訊號與政黨立場調整](projects/electoral-signals.zh-Hant.md) | 競爭者擴張時，主流政黨會回應誰的選舉訊號？ |
| [適應性聯盟與政黨延續](projects/adaptive-alliances.zh-Hant.md) | 聯盟策略如何同時容納政治適應與組織延續？ |
| [政黨組織與入閣](projects/party-organisation-and-government-entry.zh-Hant.md) | 民粹政黨的內部組織，可能如何與取得執政機會相關？ |
| [政策承諾與聯盟協商](projects/policy-commitments.zh-Hant.md) | 明確的政策承諾何時增強協商可信度，何時限制聯盟彈性？ |

## 研究取向

這個主題著重政治問題、制度機制及行為者之間的關係。各項目以易讀的文字介紹研究思路。

[瀏覽其他研究主題](https://github.com/YANG-ZHANGY/YANG-ZHANGY#research-themes)
